**Supply Chain Dataset Analysis**

**Project Idea**

This project focuses on analyzing the Bullwhip Effect in supply chains.
It explores how small changes in customer demand can become larger fluctuations as orders move from retailers to distributors, manufacturers, and suppliers.
The goal is to understand how miscommunication and lack of demand visibility create inefficiencies in the supply chain.
It also examines how factors such as lead time, demand signaling, and order batching amplify demand variations.
The objective is to identify the causes of inventory surplus, production imbalance, and increased operational costs.
The analysis aims to provide insights that can help organizations improve coordination, reduce demand distortion, and make better supply chain decisions.
****

**The project includes:**

Data preprocessing and cleaning

Exploratory Data Analysis (EDA)

Data analysis to identify patterns and relationships within the dataset

Forecasting analysis based on trends found in the data

Building an interactive visualization dashboard using Tableau

Preparing a final report and presentation summarizing the analysis and insights
